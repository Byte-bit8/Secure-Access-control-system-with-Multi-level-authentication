# Secure-Access-control-system-with-Multi-level-authentication
## ✒️Project Overview
The secure access control system uses a LPC2148 ARM7 Microcontroller with password and Fingerprint supported authentication.

It uses a  R305 fingerprint sensor for fingerprint recognition and EEPROM for password credential management.It also feature a motorized door locking system.

## 🎯Project Aim
The aim of this project is to design and develop a secure access control system that
provides multi-level user authentication to prevent unauthorized entry. It improves security, reliability, and user
verification accuracy compared to single-level authentication systems. The system
verifies a user in three stages: 
- checks the User ID, then the password, and
finally the fingerprint.
- Checks if three authentication levels are successfully
verified.
- Access is granted. 

## ⭐Features
- Password Authentication
- Fingerprint Enrollment
- Fingerprint Verification
- Fingerprint Deletion
- User Access Modes
- EEPROM Credential Storage
- UART Interrupt Communication
- Motorized Door Lock Control
